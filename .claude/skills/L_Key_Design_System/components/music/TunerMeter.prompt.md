The tuner screen's core: note in Space Grotesk 96, everything technical in JetBrains Mono, needle locks orange when in tune.

```jsx
<TunerMeter note="E" octave={2} frequency={82.41} cents={-2} tuning="STANDARD" referencePitch={440} />
```

Flat moves the needle left, sharp right, in-tune locks centre and is the one place Guitar Orange means "correct" (DESIGN.md §22). Do not add a second accent colour.
