Technical fretboard for scale, mode, arpeggio and CAGED views. Supports 6/7/8-string and bass by passing more `strings`.

```jsx
<Fretboard frets={12} markers={[{string:5,fret:5,label:"A",root:true},{string:5,fret:7,label:"B"}]} />
```

Root markers are Guitar Orange, everything else black. Fret numbers are mono 10 in `--lk-grey-300`.
