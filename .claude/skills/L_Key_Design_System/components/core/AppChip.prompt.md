Displays one precise musical or metadata fact in JetBrains Mono. Never use it as a button.

```jsx
<AppChip label="KEY">G Major</AppChip>
<AppChip variant="bento" label="FORMULA">1 3 5</AppChip>
<AppChip variant="accent">120 BPM</AppChip>
<AppChip variant="tag">C#m</AppChip>
```

`bento` is the centred label-over-value block used under the chord diagram; `accent` is the orange badge that sits on song artwork.
